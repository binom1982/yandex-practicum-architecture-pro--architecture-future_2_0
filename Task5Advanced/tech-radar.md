# Расширенный технический радар «Будущее 2.0

## Легенда статусов

* **Adopt** — использовать активно, рекомендовать для новых проектов
* **Trial** — пробовать в ограниченных проектах, оценивать применимость
* **Assess** — изучать, оценивать целесообразность внедрения
* **Hold** — не использовать для новых проектов, поддерживать только существующие

## Критерии выбора технологий

1. **Open-source приоритет** — снижение затрат на лицензии
2. **Cloud-native** — готовность к работе в Kubernetes
3. **Масштабируемость** — горизонтальное масштабирование
4. **Сообщество и поддержка** — активное развитие, документация
5. **Безопасность** — соответствие требованиям к медицинским/финансовым данным
6. **Интеграция** — поддержка стандартов (REST, gRPC, Kafka, SQL)
